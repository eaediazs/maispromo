# Project Directives: Impeccable Design Standard

All frontend and visual design work in this workspace must adhere to the Impeccable Design system.

## 1. Quality & Craftsmanship

- **Production-grade craft:** Distinctive, polished, and purposeful interfaces.
- **Brand fidelity:** Respect existing brand palette, tokens, typography, and UX flow.
- **No AI clichés:**
  - Avoid generic Inter/Arial or system font defaults for display lettering.
  - Avoid purple-to-blue gradients, neon glow text, and gradient headings.
  - Avoid nested cards and uniform card grids.
  - Avoid zero-blur hard block shadows; use subtle, realistic depth.
  - Avoid bounce or elastic easing; use smooth exponential ease-out curves.
  - Never use plain gray text on colored backgrounds; tint secondary text from the background hue.

## 2. Impeccable Commands

The Impeccable skill is installed in `.agents/skills/impeccable`. You can invoke it via:
- `/impeccable audit` - Technical checks (a11y, responsiveness, performance)
- `/impeccable critique` - UX hierarchy, heuristics, and clarity review
- `/impeccable polish` - Final finishing pass before shipping
- `/impeccable shape` - Planning UX and interface structure before coding
- `/impeccable bolder` / `/impeccable quieter` - Adjusting visual intensity
- `/impeccable harden` - Edge cases, error states, and responsive resilience
